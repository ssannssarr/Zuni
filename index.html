    Research, withoutleaving your terminal.

    Zuni pairs an OpenAI-compatible model with web search, reads the pages it finds, and answers your question with source citations, right where you already work.

    02 HOW IT WORKS

    From question to citation.

    Four steps, every time you run zuni ask. Follow one question through.

    INPUT

    $ zuni ask "What is quantum computing?"

    0104
    01
    STEP 01 ASK

    You ask a question.

    Type it the way you'd say it. Zuni takes the question straight from the command line. No browser tab, no context switch.

    INPUT

    $ zuni ask "What is quantum computing?"

    02
    STEP 02 SEARCH

    The web gathers context.

    Zuni searches the web and extracts readable page content, so the model gets useful text rather than raw markup.

    --no-search skips this step · -n sets the result count

    SEARCH → READABLE TEXT

    search result → extracted page text

    03
    STEP 03 SYNTHESIZE

    Your model writes the answer.

    The context goes to the OpenAI-compatible endpoint you configured: your API key, model ID, and base URL.

    ZUNI CONFIG

    API key ••••••••
    model ID <your model>
    base URL <your endpoint>

    STEP 04 CITE

    The answer prints in your terminal with its source references, so you can inspect the material behind a claim.

    03 FEATURES

    Small surface.
    Sharp edges.

    Four capabilities, straight from the project. That's the whole tool, and that's the point.

    1. 01

      Automatic web search

      Search the web by default, then use retrieved pages to ground an answer beyond model memory alone.

      zuni ask -n 3 "…"zuni ask --no-search "…"
    2. 02

      Readable page extraction

      Extract readable content from result pages and give the model useful text to reason over.

      page → readable texttext → model context
    3. 03

      Source citations

      Get answers with source references printed beneath the response, ready for you to inspect.

      [1] source url[2] source url
    4. 04

      OpenAI-compatible endpoints

      Use a compatible API endpoint and configure your key, model, and base URL with zuni config.

      zuni configOpenAI-style API
    04 QUICK START

    Four commands to a first answer.

    1. 01

      Install from PyPI

      uv tool install ssannssarr.zuni

      Requires Python 3.11 or newer and uv.

    2. 02

      Verify the install

      zuni --help

      See the available commands and options.

    3. 03

      Configure your model

      zuni config

      Set your API key, model ID, and compatible base URL.

    4. 04

      Ask your first question

      zuni ask "What is quantum computing?"

      Add --no-search to skip web research or -n to set the result count.
